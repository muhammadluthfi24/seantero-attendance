# Aplikasi Absensi Seantero V1.0

**Copyright © 2025 Muhammad Luthfi Farizqi. All rights reserved.**

Aplikasi Absensi Seantero adalah sistem absensi berbasis web yang memudahkan pengelolaan kehadiran pegawai menggunakan QR Code.

## Teknologi yang Digunakan
- PHP 8.x
- MySQL / MariaDB
- HTML, CSS, JavaScript
- QR Code generator library
